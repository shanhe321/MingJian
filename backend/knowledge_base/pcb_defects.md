# PCB 缺陷检测知识

## PCB 图像与质检特点

印制电路板（Printed Circuit Board，PCB）承担元器件承载、电气连接和信号传输等功能。PCB 线路通常具有高密度、重复纹理多、线宽较细等特点，生产过程中的局部缺陷可能影响电路连通性和产品可靠性。

PCB 缺陷图像常具有以下特点：

1. **缺陷区域较小**：缺陷可能只占整张图像很少的像素，容易漏检
2. **背景纹理重复**：线路、焊盘和孔位结构相似，容易产生误检
3. **类别外观接近**：毛刺、多余铜、鼠咬等缺陷在局部区域可能较难区分
4. **成像条件有差异**：光照、拍摄角度、清晰度和板面反光会影响图像质量
5. **定位精度要求高**：检测框需要准确覆盖缺陷，便于复检和后续质检分析

## 本项目支持的六类 PCB 缺陷

1. **漏孔（missing_hole）**：PCB 中应存在的孔位未正常形成，可能影响元器件安装或电气连接
2. **鼠咬（mouse_bite）**：板边或导电线路区域出现类似啃咬形状的缺损，可能造成线路宽度不足
3. **断路（open_circuit）**：导电线路发生断开，可能导致电路无法正常连通
4. **短路（short）**：原本不应连接的线路发生连接，可能造成电路异常或器件损坏
5. **毛刺（spur）**：线路边缘出现多余的尖状或条状突起，可能影响电气性能和制造质量
6. **多余铜（spurious_copper）**：板面存在不应出现的铜区域，可能形成潜在短路风险

系统展示结果时应同时保留英文类别名称和中文名称。英文名称用于与数据集标注、模型类别编号保持一致，中文名称便于质检人员理解。

## PCB 缺陷检测的主要挑战

1. **小目标检测**：细微断路、毛刺或多余铜区域尺寸较小，需要模型保留高分辨率特征
2. **类间相似性**：不同缺陷可能具有相似边缘或纹理，需要结合局部结构进行判断
3. **类内差异**：同一类缺陷的形状、尺寸和位置可能差异较大
4. **样本不均衡**：不同缺陷类别的样本数量可能不一致，容易造成模型偏向高频类别
5. **图像配准误差**：模板图与检测图存在偏移时，可能把正常线路差异误判为缺陷
6. **噪声与反光**：模糊、压缩噪声、板面污渍和反光可能降低检测稳定性

## 数据增强策略

针对 PCB 缺陷数据可使用以下增强方法：

1. **翻转与小角度旋转**：增强模型对不同板面方向和拍摄角度的适应能力
2. **随机缩放与裁剪**：提高模型对不同缺陷尺度和局部区域的识别能力
3. **亮度与对比度调整**：模拟光照和曝光差异，但应避免掩盖细小缺陷
4. **轻度模糊与噪声**：提高模型对成像噪声和轻微失焦的鲁棒性
5. **Mosaic 与 MixUp**：增加训练样本组合的多样性，但需要观察是否破坏 PCB 线路结构
6. **类别均衡采样**：适当增加低频缺陷类别的采样概率，缓解类别不均衡

所有增强操作都必须同步更新检测框标注，且不能生成不符合 PCB 结构规律的伪缺陷。

## 风险等级与质检结论

根据项目需求，风险等级可结合缺陷类别、数量和置信度进行辅助判断：

- **低风险**：轻微毛刺、疑似多余铜或低置信度缺陷，建议人工复核
- **中风险**：鼠咬、多处轻微缺陷或影响范围较小的缺陷
- **高风险**：短路、断路、漏孔等可能直接影响电路连通性的缺陷

质检结论可分为：

- **合格**：未检测到明显缺陷
- **疑似缺陷**：存在低置信度或不确定检测结果，建议人工复检
- **不合格**：检测到短路、断路、漏孔等严重缺陷

风险等级和质检结论属于辅助分析结果，不能仅凭模型预测替代最终人工质检。实际结论还应结合置信度、缺陷位置、缺陷数量、生产标准和人工复核结果。

## 检测结果解读

平台的检测结果通常包含缺陷类别、置信度、边界框、缺陷数量和推理耗时：

- **缺陷类别**表示模型判断的缺陷类型
- **置信度**表示模型对预测结果的确信程度，不等同于结果一定正确
- **边界框**表示缺陷在图像中的位置，用于标注和人工复核
- **缺陷数量**用于统计当前图片或任务中的缺陷分布
- **推理耗时**表示模型完成推理所需的时间，不包含全部文件上传和网络传输时间

置信度较低的结果应重点复核。提高置信度阈值通常可以减少误检，但可能增加漏检；降低阈值通常可以提高召回率，但可能产生更多误检。
